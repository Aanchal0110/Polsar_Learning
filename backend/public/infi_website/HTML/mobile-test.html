Mobile Navbar Test Page

This page is designed to test the mobile responsiveness of the navbar.

Testing Instructions:

  • Resize your browser window to mobile size (768px or less)
  • Look for the hamburger menu (☰) button in the top-right corner
  • Click the hamburger menu to open/close the mobile navigation
  • Test clicking outside the menu to close it
  • Test clicking on navigation links to close the menu
  • Test window resize to ensure menu closes when switching to desktop

Expected Behavior:

  • On desktop: Full horizontal navbar should be visible
  • On mobile: Hamburger menu should be visible, navbar hidden by default
  • Clicking hamburger menu should toggle navbar visibility
  • Menu should close when clicking outside or on links
  • Menu should close when resizing to desktop view
