Open Source Software

SNAP

Open Source

All Sentinel Toolboxes is being jointly developed by Brockmann Consult, SkyWatch and C-S called the Sentinel Application Platform (SNAP). The SNAP architecture is ideal for Earth Observation processing and analysis due to the following technological innovations: Extensibility, Portability, Modular Rich Client Platform, Generic EO Data Abstraction, Tiled Memory Management, and a Graph Processing Framework.

SNAP Website

QGIS

Open Source

A full‑featured open‑source GIS platform with strong raster handling, classification, change detection, and seamless integration with GRASS GIS, Orfeo Toolbox (OTB), and SAGA. Rich plug‑in ecosystem supports remote sensing workflows end‑to‑end.

QGIS Website

GRASS GIS

Open Source

One of the oldest open‑source GIS tools with a powerful raster engine. Advanced terrain analysis, image classification, and change detection; integrates tightly with QGIS.

GRASS GIS Website

Orfeo Toolbox (OTB)

Open Source

Remote sensing image processing focused toolkit. Excellent for very high‑resolution data, classification, segmentation, and object‑based image analysis; integrates with QGIS.

OTB Website

SAGA GIS

Open Source

Known for its extensive geoscientific analysis modules. Strong in terrain modeling, hydrology, and raster processing; available from within QGIS via toolboxes.

SAGA GIS Website

ILWIS

Open Source

Integrated Land and Water Information System, originally from ITC (Netherlands), now open‑source via 52°North. Good for land‑cover classification, remote sensing, and raster analysis.

ILWIS Project Page

Google Earth Engine (GEE)

Free for research

Cloud platform for planetary‑scale analysis of satellite imagery and geospatial datasets. Provides petabyte‑scale data catalog, JavaScript/Python APIs, and built‑in ML tools. Free for research and education.

Earth Engine Website

POLSAR

Open Source

POLSAR is a comprehensive software package for polarimetric SAR data processing and analysis. It provides tools for processing, analyzing, and visualizing polarimetric SAR data from various satellite missions.

POLSAR Website

VEDAS

Open Source

VEDAS (Visualization of Earth observation Data and Archival System) is an open-source software developed by ISRO for processing and analyzing Earth observation data. It provides tools for satellite data processing, analysis, and visualization.

VEDAS Website

Proprietary Software

ERDAS Imagine

Proprietary

ERDAS Imagine is ranked as the #1 remote sensing and image analysis software suite. Developed by Hexagon Geospatial, it can handle virtually any type of geospatial data, including satellite imagery, aerial photography, LiDAR point clouds, digital elevation models, and other GIS data.

ERDAS Imagine Website

ENVI (NV5 Geospatial)

Proprietary

ENVI is an advanced remote sensing software platform from NV5 Geospatial. With ENVI, users can quickly extract information from satellite, airborne, and other types of imagery by leveraging the latest in image processing technology. It provides support for a wide range of data formats and offers powerful automation capabilities through ENVI modeler.

ENVI Website

PCI Geomatica (Catalyst)

Proprietary

PCI Geomatica is an advanced remote sensing software suite used by scientists, researchers, and GIS professionals around the world. Developed by Canadian company PCI Geomatics, users can access and analyze satellite imagery, aerial photography, and other types of remotely sensed data including SAR and InSAR data.

PCI Geomatica Website

ArcGIS Pro

Proprietary

ArcGIS Pro supports SAR sensors with raster products and raster types. This allows you to add SAR data to your map directly from the original dataset, without the need for additional import or conversion tools. Currently, the SAR raster types support Capella, ICEYE, RADARSAT-2, RADARSAT Constellation Mission (RCM) and Sentinel-1.

ArcGIS Pro Website

TerrSet (Clark Labs)

Proprietary

TerrSet is an integrated geospatial software system for monitoring and modeling the Earth system for sustainable development. It offers 300+ raster analysis tools for image processing, change detection, surface analysis, decision support, and more. Vertical modules include Land Change Modeler, Earth Trends Modeler, and Habitat & Biodiversity Modeler. Supports major raster/vector formats and scripting (e.g., Python).

TerrSet Website

SOCET GXP (BAE Systems)

Proprietary

SOCET GXP is a geospatial‑intelligence solution for analyzing satellite and aerial imagery, supporting advanced photogrammetry, remote sensing, LiDAR, multispectral/hyperspectral processing, and AI/ML‑enabled object detection. Includes 3D visualization, terrain modeling, orthorectification, and sensor models. Modular licensing provides bundles for capabilities such as GeoAnalysis, LiDAR, and SAR.

SOCET GXP Website
