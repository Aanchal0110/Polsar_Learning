Open Source Software

SNAP

Open Source

All Sentinel Toolboxes is being jointly developed by Brockmann Consult, SkyWatch and C-S called the Sentinel Application Platform (SNAP). The SNAP architecture is ideal for Earth Observation processing and analysis due to the following technological innovations: Extensibility, Portability, Modular Rich Client Platform, Generic EO Data Abstraction, Tiled Memory Management, and a Graph Processing Framework.

Download SNAP

POLSAR

Open Source

POLSAR is a comprehensive software package for polarimetric SAR data processing and analysis. It provides tools for processing, analyzing, and visualizing polarimetric SAR data from various satellite missions.

Download POLSAR

VEDAS

Open Source

VEDAS (Visualization of Earth observation Data and Archival System) is an open-source software developed by ISRO for processing and analyzing Earth observation data. It provides tools for satellite data processing, analysis, and visualization.

Download VEDAS

Proprietary Software

ERDAS Imagine

Proprietary

ERDAS Imagine is ranked as the #1 remote sensing and image analysis software suite. Developed by Hexagon Geospatial, it can handle virtually any type of geospatial data, including satellite imagery, aerial photography, LiDAR point clouds, digital elevation models, and other GIS data.

ENVI (NV5 Geospatial)

Proprietary

ENVI is an advanced remote sensing software platform from NV5 Geospatial. With ENVI, users can quickly extract information from satellite, airborne, and other types of imagery by leveraging the latest in image processing technology. It provides support for a wide range of data formats and offers powerful automation capabilities through ENVI modeler.

Learn More

PCI Geomatica (Catalyst)

Proprietary

PCI Geomatica is an advanced remote sensing software suite used by scientists, researchers, and GIS professionals around the world. Developed by Canadian company PCI Geomatics, users can access and analyze satellite imagery, aerial photography, and other types of remotely sensed data including SAR and InSAR data.

ArcGIS Pro

Proprietary

ArcGIS Pro supports SAR sensors with raster products and raster types. This allows you to add SAR data to your map directly from the original dataset, without the need for additional import or conversion tools. Currently, the SAR raster types support Capella, ICEYE, RADARSAT-2, RADARSAT Constellation Mission (RCM) and Sentinel-1.
